# Photo Collection

Pet-проект — веб-приложение для управления коллекцией фотографий с категориями, поиском и пагинацией.

## Функциональность

- 🖼 Отображение фотоальбомов в виде карточек с превью
- 🔍 Поиск альбомов по названию
- 🏷 Фильтрация по категориям (Море, Горы, Архитектура, Города)
- 📄 Пагинация для навигации по большому количеству альбомов
- 📱 Адаптивная верстка

## Стек технологий

- React
- SCSS
- JavaScript
- Create React App

## Запуск проекта

```bash
npm install
npm start
```

## О проекте

Проект реализован в учебных/тренировочных целях для практики работы с React: управление состоянием (фильтры, поиск, пагинация), компонентная структура и стилизация через SCSS.
